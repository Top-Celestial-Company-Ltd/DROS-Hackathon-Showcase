3. Tool / Action (工具邊界) 能呼叫什麼工具？權限與邊界為何？ VEP Interceptor 帶內代理，嘗試呼叫 `execute_payment` 在微秒級退回。 [TOOL_INTERCEPT] Tool: execute_payment -> DENIED
4. Policy Gate (過濾門閥) 高風險/敏感動作如何被攔擋與把關？ Privacy Gate & HITL Suspended，完全去識別化購物明細，洗錢爆表時硬性掛起懸停要求 MFA。 [POLICY_GATE] Required HITL Approval

6. Revocation (動態撤銷) 授權過期或撤銷後，如何阻止 Agent 繼續執行？ $O(1)$ 常數時間 Payment Token 凍結，風控中心點擊凍結，支付 API 權限秒級失效傳回 `403`。 [RISK_FREEZE] Token invalidated -> 403
